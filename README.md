# Molecular Communication Channel as a Physical Reservoir Computer 🔬

![MATLAB](https://img.shields.io/badge/MATLAB-R2021b%2B-orange)
![Smoldyn](https://img.shields.io/badge/Smoldyn-v2.60%2B-blue)

This repository contains the MATLAB and Smoldyn code for the paper "Molecular Communication Channel as a Physical Reservoir Computer." The project reconceptualizes the intrinsic memory and nonlinear dynamics of a molecular communication (MC) channel as computational resources.

We frame a canonical point-to-point MC channel, featuring ligand diffusion and reversible receptor binding, as a physical reservoir computer (PRC). The system's performance is evaluated on its ability to perform complex temporal processing, specifically next-step prediction on standard chaotic time-series benchmarks (Mackey-Glass and NARMA10). Additionally, the reservoir's fundamental computational properties are characterized using Information Processing Capacity (IPC) analysis.

The workflows are implemented using two complementary simulation approaches:
1.  **Deterministic Mean-Field Modeling** in MATLAB for rapid parameter analysis.
2.  **Particle-Based Spatial Stochastic Simulations** using the **Smoldyn** simulator to account for intrinsic molecular noise.

## Required Dependencies
* **MATLAB**: The primary environment for all analysis and orchestration scripts.
* **Smoldyn**: An external, open-source particle simulator. It must be installed and accessible from the system's command line for the stochastic simulation scripts to function.

## Overall Workflow
The project is divided into several analysis paths. The first two evaluate performance on specific benchmark tasks, the third provides a fundamental, task-independent characterization of the reservoir's computational power, and the new workflows introduce hyperparameter optimization and advanced post-processing.

### Workflow 1: Mackey-Glass Prediction Task 📈
This workflow evaluates the reservoir's ability to predict the future values of the chaotic Mackey-Glass time series.

**Scripts & Execution Order:**

1.  `createMGseries.m`
    * **Purpose**: Generates the Mackey-Glass time-series data.
    * **Note**: **Run this first** to create the `MGseries_RK4_....mat` data file.

2.  `NewMG_Generate_Smoldyn_Data.m` (Optional - for Stochastic Simulation)
    * **Purpose**: Runs a full Smoldyn simulation to generate high-fidelity reservoir states.

3.  **Analysis Scripts (Choose one):**
    * `mg_numerical_analysis.m`: Sweeps parameters using the fast deterministic mean-field model.
    * `mg_stochastic_sweep.m`: The main analysis hub for this task. It compares the performance of the deterministic model against pre-computed Smoldyn data.

---

### Workflow 2: NARMA10 Prediction Task 🧠
This workflow evaluates the reservoir on the NARMA10 benchmark.

**Scripts & Execution Order:**

1.  `NARMA10_Generate_Smoldyn_Data.m` (Optional - for Stochastic Simulation)
    * **Purpose**: Runs a full Smoldyn simulation for the NARMA10 task.

2.  **Analysis Scripts (Choose one):**
    * `narma_numerical_analysis.m`: Sweeps parameters using the fast deterministic model.
    * `narma_stochastic_sweep.m`: The main analysis hub for this task, comparing deterministic and stochastic results.

---

### Workflow 3: Information Processing Capacity (IPC) Analysis 📊
This workflow provides a task-independent characterization of the reservoir's computational power.

**Scripts & Execution Order:**

1.  `IPC_sweep.m` (Main Script)
    * **Purpose**: Performs the complete IPC analysis.
    * **Core Functionality**: Calls `computeIPC_legendreNoZeroDup.m`.
    * **Output**: Heatmap plots showing the **Total IPC**.

---

### New Workflow 4: Bayesian Hyperparameter Optimization 🎯
This workflow uses Bayesian optimization to find the optimal hyperparameters for the reservoir computer.

**Scripts:**
* `optimize_mg_hyperparams_bayesopt.m`: For the Mackey-Glass task.
* `optimize_narma_hyperparams_bayesopt.m`: For the NARMA10 task.

---

### New Workflow 5: Kathy Ludge Post-Processing Analysis 🛠️
This workflow applies Kathy Ludge post-processing methods to the reservoir's output for improved performance.

**Scripts:**
* `kl_mg_numerical_analysis.m` and `kl_mg_stochastic_sweep.m`: For the Mackey-Glass task.
* `kl_narma_numerical_analysis.m` and `kl_narma_stochastic_sweep.m`: For the NARMA10 task.
* `optimize_kl_mg_hyperparams.m` and `optimize_kl_narma_hyperparams.m`: For optimizing the hyperparameters of the Kathy Ludge methods.

## Core Simulation Framework (Smoldyn) 🧬
The project's high-fidelity stochastic simulations are managed by a two-part framework that automates the execution of the external Smoldyn simulator.

* `MCsimulationframework.m` **(MATLAB Driver)**: This script acts as the orchestrator.
* `MCpointTXsphRX.txt` **(Smoldyn Template)**: This is a generic template file that defines the core physics of the MC channel.
