# Molecular Communication Channel as a Physical Reservoir Computer 🔬

![MATLAB](https://img.shields.io/badge/MATLAB-R2021b%2B-orange)
![Smoldyn](https://img.shields.io/badge/Smoldyn-v2.60%2B-blue)

This repository contains the MATLAB and Smoldyn code for the paper "Molecular Communication Channel as a Physical Reservoir Computer." The project reconceptualizes the intrinsic memory and nonlinear dynamics of a molecular communication (MC) channel as computational resources.

We frame a canonical point-to-point MC channel, featuring ligand diffusion and reversible receptor binding, as a physical reservoir computer (PRC). The system's performance is evaluated on its ability to perform complex temporal processing, specifically next-step prediction on standard chaotic time-series benchmarks (Mackey-Glass and NARMA10). Additionally, the reservoir's fundamental computational properties are characterized using Information Processing Capacity (IPC) analysis.

The workflows are implemented using two complementary simulation approaches:
1.  **Deterministic Mean-Field Modeling** in MATLAB for rapid parameter analysis.
2.  **Particle-Based Spatial Stochastic Simulations** using the **Smoldyn** simulator to account for intrinsic molecular noise.

---

## Required Dependencies
* **MATLAB**: The primary environment for all analysis and orchestration scripts.
* **Smoldyn**: An external, open-source particle simulator. It must be installed and accessible from the system's command line for the stochastic simulation scripts to function.

## Overall Workflow
The project is divided into three distinct analysis paths. The first two evaluate performance on specific benchmark tasks, while the third provides a fundamental, task-independent characterization of the reservoir's computational power.

### Workflow 1: Mackey-Glass Prediction Task 📈
This workflow evaluates the reservoir's ability to predict the future values of the chaotic Mackey-Glass time series.

**Scripts & Execution Order:**

1.  `createMGseries.m`
    * **Purpose**: Generates the Mackey-Glass time-series data by numerically integrating the time-delayed differential equation using the 4th-order Runge-Kutta method.
    * **Note**: **Run this first** to create the `MGseries_RK4_....mat` data file.

2.  `NewMG_Generate_Smoldyn_Data.m` (Optional - for Stochastic Simulation)
    * **Purpose**: Runs a full Smoldyn simulation to generate high-fidelity reservoir states for the Mackey-Glass task. It loads the `.mat` file, writes a simulation configuration, and executes Smoldyn externally.
    * **Output**: Creates a data directory (e.g., `MG_5000_T1_koff1/`) filled with `.txt` simulation results.

3.  **Analysis Scripts (Choose one):**
    * `NewMG_Only_Numerical_Sweep.m` (Fast Exploration): Sweeps parameters using only the fast deterministic mean-field model. (Approx. 5-8 hours runtime).
    * `NewMG_Stochastic_Sweep.m` (Final Comparison): The main analysis hub for this task. It compares the performance of the deterministic model against pre-computed Smoldyn data. (Approx. 30 mins per run; a full 10x10 sweep can take ~25-30 hours).

---

### Workflow 2: NARMA10 Prediction Task 🧠
This workflow evaluates the reservoir on the NARMA10 benchmark, which tests for long-term memory and nonlinear processing capabilities.

**Scripts & Execution Order:**

1.  `NARMA10_Generate_Smoldyn_Data.m` (Optional - for Stochastic Simulation)
    * **Purpose**: Runs a full Smoldyn simulation for the NARMA10 task. It generates the NARMA10 input signal internally (using `rng(0)` for reproducibility) and executes Smoldyn externally.
    * **Output**: Creates a data directory (e.g., `NARMA_5000_T1_koff1/`).

2.  **Analysis Scripts (Choose one):**
    * `NARMA10_Only_Numerical_Sweep.m` (Fast Exploration): Sweeps parameters using the fast deterministic model. (Approx. 5-8 hours runtime).
    * `NARMA_Stochastic_Sweep.m` (Final Comparison): The main analysis hub for this task, comparing deterministic and stochastic results. (Approx. 30 mins per run; a full sweep can take ~24 hours).

---

### Workflow 3: Information Processing Capacity (IPC) Analysis 📊
This workflow provides a task-independent characterization of the reservoir's computational power, quantifying its linear memory and nonlinear processing capabilities.

**Scripts & Execution Order:**

1.  `IPC_sweep.m` (Main Script)
    * **Purpose**: Performs the complete IPC analysis by sweeping through physical parameters (`k_on`, `k_off`, etc.) and calculating the total IPC for each configuration.
    * **Core Functionality**: Calls `computeIPC_legendreNoZeroDup.m` to enumerate a basis of Legendre polynomials and calculate the reservoir's capacity for each one.
    * **Output**: Heatmap plots showing the **Total IPC** as a function of the swept physical parameters.

## Core Simulation Framework (Smoldyn) 🧬
The project's high-fidelity stochastic simulations are managed by a two-part framework that automates the execution of the external Smoldyn simulator.

* `MCsimulationframework.m` **(MATLAB Driver)**: This script acts as the orchestrator. It sets simulation parameters in MATLAB, creates organized output directories, and launches Smoldyn by dynamically building a command-line instruction.

* `MCpointTXsphRX.txt` **(Smoldyn Template)**: This is a generic template file that defines the core physics of the MC channel, including the 3D geometry, molecular species, reaction dynamics, and a probabilistic binary communication scheme. The MATLAB driver uses Smoldyn's `--define` feature to inject parameters from the sweep into this template at runtime.

The more specialized scripts like `NewMG_Generate_Smoldyn_Data.m` adapt this core framework by using the `generateSimConfig.m` helper to create a custom Smoldyn configuration file tailored to their specific analog input signals (Mackey-Glass or NARMA10).
